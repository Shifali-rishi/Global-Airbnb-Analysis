# Global Airbnb Performance Dashboard

## Overview

This project presents a comprehensive analysis of Airbnb's performance across major global cities. The dashboard explores listing growth, customer review behavior, host trust indicators, pricing patterns, market share distribution, and city-level ratings.

The analysis highlights key trends in Airbnb's expansion, seasonal demand, customer engagement, and property performance. Interactive visualizations provide insights that can support business decisions, market evaluation, and customer experience analysis.

### Key Areas Covered

* Airbnb growth and listing trends
* Review frequency analysis
* Host trust and verification insights
* Seasonal review patterns
* City-wise market share
* Property pricing comparison
* Customer ratings and satisfaction metrics

This dashboard demonstrates the use of data visualization and storytelling to transform raw data into actionable insights.
