# 🏡 Global Airbnb Performance Dashboard

## Overview

The Global Airbnb Performance Dashboard provides a comprehensive analysis of Airbnb listings across major cities worldwide. The dashboard explores growth trends, review behavior, host trust indicators, market share, pricing patterns, and customer satisfaction metrics to uncover valuable business insights.

Through interactive visualizations, this project helps understand how Airbnb has evolved over time, which cities dominate the market, how customers engage with listings, and how property types perform across different regions.

## Key Insights

* Airbnb experienced rapid growth between 2011 and 2015.
* Most customers leave only a small number of reviews.
* Verified hosts represent the majority of listings.
* Paris, New York, and Sydney lead in market presence.
* Hotel rooms have the highest average prices among property types.
* Customer ratings vary significantly across cities, highlighting differences in guest experience.

This dashboard demonstrates how data visualization can transform large datasets into meaningful insights for decision-making and market analysis.
